## 🎯 Aim
To consume a REST API in React and handle asynchronous data with loading, error, and empty states using `useEffect` and dynamic card rendering.

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **API Source:** GitHub REST API (`https://api.github.com/users/Dhyey-Ghoniya/repos`)
- **Lifecycle Management:** React `useEffect` and `useState` hooks

## 📂 Project Structure
